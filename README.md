# 材料硬度对比 · Hardness Comparator

一个单文件、离线可用的材料硬度对比工具。选两个材料比硬度，或一次加入多个材料统一排序。

**在线使用**：https://3698688050-pixel.github.io/hardness-comparator/

## 功能

- **两两对比**：选 A、B 两个材料，直接给出谁更硬、差多少
- **批量对比**：一次加入最多 12 个材料，按硬度统一排序，支持导出 CSV 与打印 / PDF
- **硬度数据库**：106 条材料，涵盖矿物粉体、金属合金、陶瓷玻璃、塑料橡胶
- **多标度换算**：莫氏 / 维氏 HV / 洛氏 HRC·HRA / 布氏 HB / 邵氏 A·D 统一换算后比较
- **检索**：支持中文名、别名、英文名、化学式，如「重钙」「SiO2」「quartz」「304」

## 设计要点

### 标度不可直接比较

莫氏是刻划标度（1–10，等级差不是倍数），HV / HRC / HB 是压入标度，邵氏是回弹标度。程序把所有值换算到统一基准后排序，并在结果中**如实标注来源**：

> 45 钢（淬火）：莫氏 5.8（HRC 55 换算）· 维氏 HV 595

换算值会明确标出，不会把换算数当作实测值。

### 邵氏 A 与 D 不混排

批量对比中，硬质材料按 HV 排序；邵氏 D（硬质塑料）与邵氏 A（软质橡胶）各自单独成组。邵氏 A 与 D 之间没有通用换算关系，混排会得出错误结论。

### 金属区分热处理状态

「45 钢」不是一个硬度，是三个：退火 4.5、调质 5.2、淬火 5.8（莫氏）。库里分开建了三条，选错状态就会得出错误结论。

### 条形图用对数量尺

硬度跨 4 个数量级（铅 HV 5 → 金刚石 HV 10000），线性刻度会让所有软材料挤成一团。条形按 HV 对数映射，才看得出铅与锡的差异。

## 局限

- 同一材料在不同文献中「莫氏」与「HV」的对应常有 ±0.5 级偏差（脆性与解理方式不同所致）。表中莫氏优先采用文献实测值，无实测值时由 HV 换算并标注。
- 金属硬度随热处理、冷加工、合金牌号显著变化，表中为典型值且已标注状态。
- 换算关系为经验对应，本工具用于排序与直观比较，**不作为材料验收依据**。精确数据请查质保书或实测。
